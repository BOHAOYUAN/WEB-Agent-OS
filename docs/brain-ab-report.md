# Brain 模型 A/B 质量门禁报告

结论：**FAIL — 1.5B 不达标**

基线 `qwen2.5:3b` vs 候选 `qwen2.5:1.5b`，样本 10 条 × 3 轮 = 每模型 30 次推理。

## 聚合指标

| 指标 | 基线 3B | 候选 1.5B |
|---|---|---|
| JSON 合规率 | 100% | 97% |
| 事实召回率 | 52% | 24% |
| facts 边界违规率（守卫前） | 4% | 7% |
| open_loops 归因率 | 19% | 11% |
| preferences 归因率 | 20% | 20% |
| facts 超字数率 | 0% | 0% |
| 压缩比（越低越好，>0.35 视为在抄原文） | 0.17 | 0.28 |
| 中位延迟 | 1222.5 ms | 879 ms |
| 中位生成速度 | 120.5 tok/s | 184.6 tok/s |
| 各轮召回率 | 52% / 57% / 48% | 26% / 20% / 26% |

## 门禁判定

- PASS JSON 合规率 — 97% ≥ 95%
- FAIL 召回率保持比 — 46% of baseline（24% vs 52%）≥ 85%
- PASS facts 边界违规（绝对值） — 7% ≤ 25%
- FAIL facts 边界违规（相对基线） — 1.88x ≤ 1.5x
- FAIL open_loops 归因保持比 — 55% of baseline ≥ 80%
- PASS 压缩比（facts 文本 / 输入长度） — 0.28 ≤ 0.35（基线 0.17）

阈值在 `scripts/brain-ab/index.ts` 顶部固定，跑之前就写死，不做事后调整。

样本为按本项目真实素材风格编写的合成对话（非抓取的用户数据）。
